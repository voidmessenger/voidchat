# VOIDCHAT — UI starter

Стартовый интерфейс браузерного мессенджера на React + TypeScript + Vite.

## Требования

- Node.js 20.19+ или 22.12+
- npm
- Visual Studio Code

## Запуск в Windows

1. Распакуйте архив.
2. Откройте папку `voidchat-starter` в Visual Studio Code.
3. Откройте Terminal → New Terminal.
4. Выполните:

```bash
npm install
npm run dev
```

5. Откройте локальный адрес, который Vite покажет в терминале (обычно `http://127.0.0.1:5173`).

## Что уже работает в интерфейсе

- адаптивный чёрно-фиолетовый макет;
- переключение между демонстрационными чатами;
- фильтрация чатов и поиск по списку;
- добавление локальных сообщений нажатием Enter или кнопки отправки;
- демонстрационные ответы и реакции;
- выбор файла с отображением его имени в локальном сообщении;
- информационные сообщения о функциях, которые пока не подключены.

## Важно: это пока не полноценный мессенджер

Этот starter не содержит сервера, базы данных, настоящей регистрации, синхронизации между пользователями, реальной загрузки файлов, WebRTC-звонков или E2EE. Демоданные хранятся только в состоянии страницы и пропадут при перезагрузке.

Не используйте его для реальной конфиденциальной переписки.

## Следующие этапы разработки

1. Добавить тесты и базовую настройку качества кода.
2. Спроектировать серверный API, схему PostgreSQL и авторизацию.
3. Реализовать ограничения доступа и защиту от спама/перебора.
4. Выбрать и интегрировать проверенный E2EE-протокол и библиотеку; не писать собственную криптографию.
5. Реализовать доставку зашифрованных сообщений и управление устройствами/ключами.
6. Добавить зашифрованные вложения и хранилище.
7. Добавить WebRTC, сигнализацию и TURN для звонков.
8. Настроить мониторинг, резервное копирование, rate limits, аудит безопасности и план реагирования на инциденты.
9. Провести независимый аудит безопасности до публичного запуска.
